# pixel_clau

Windows 화면 맨 앞에 떠 있는 픽셀 클로드. 클릭 한 번으로 [Claude Code](https://claude.com/claude-code)에게 질문하고,
작업 중인지 · 끝났는지를 캐릭터의 움직임으로 알려 줍니다.

## 1. 준비물

| 필요한 것 | 설명 |
|---|---|
| Windows 10 / 11 | Windows 전용입니다. |
| **Claude Code (필수)** | [claude.com/claude-code](https://claude.com/claude-code)에서 설치한 뒤, 터미널에서 `claude`를 한 번 실행해 **로그인**해 두세요. pixel_clau는 이 `claude` 명령으로 질문을 보냅니다. |
| Claude 데스크톱 앱 (선택) | 설치되어 있으면 앱의 Code 세션도 목록에 나오고 함께 쓸 수 있습니다. ([10장](#10-데스크톱-앱-세션과-함께-쓰기)) |

파이썬은 필요 없습니다 (exe 버전 기준).

## 2. 설치

1. [Releases](../../releases/latest) 페이지에서 **`pixel_clau.exe`** 를 내려받습니다.
2. 원하는 폴더(예: `C:\Tools\pixel_clau\`)에 넣습니다. 설치 과정은 없고 이 파일 하나가 전부입니다.
3. 더블 클릭해서 실행합니다.
4. 처음 실행하면 **시작 메뉴에 `pixel_clau` 아이콘**이 자동으로 생깁니다. 다음부터는 시작 메뉴에서 검색해 켜면 돼요.
   바탕화면 아이콘도 원하면 **오른쪽 클릭 → 바탕화면에 아이콘 만들기**.

> **"Windows의 PC 보호" 창이 뜨면**
> 코드 서명이 없는 exe라서 처음 한 번 뜰 수 있습니다. **추가 정보 → 실행** 을 누르세요.

## 3. 처음 실행하기

1. 실행하면 화면 오른쪽 가운데쯤에 주황색 픽셀 클로드가 나타납니다. 항상 다른 창보다 위에 떠 있어요.
2. 캐릭터를 **드래그**해서 편한 자리로 옮기세요. 위치는 자동으로 기억됩니다.
3. 캐릭터를 **한 번 클릭**하고 질문을 입력한 뒤 **Enter** — 끝입니다.

> **픽셀 전용 세션**
> pixel_clau는 켤 때마다 **자기 전용 세션**을 새로 시작합니다. 빠른 질문은 모두 여기로 가고, 답도 픽셀 안에서 바로 받습니다.
> - 전용 세션은 첫 질문을 보낼 때 만들어지고, 그 뒤 질문들은 같은 대화로 이어집니다 (앞 내용을 기억해요).
> - 작업 폴더는 `%APPDATA%\pixel_clau\pixel-claude` 입니다. 내 프로젝트 폴더와 섞이지 않아요.
> - 켜 둔 채로 새 대화를 시작하려면 **오른쪽 클릭 → 픽셀 전용 세션 (새 대화)**.
> - 특정 프로젝트에서 작업시키고 싶으면 [세션 고르기](#8-세션-고르기)나 [새 세션 만들기](#9-새-세션-만들기)를 쓰세요.

## 4. 기본 조작 한눈에 보기

| 조작 | 하는 일 |
|---|---|
| **클릭** | 도트 입력창 열기 / 다시 클릭하면 닫기 |
| **길게 누르기** (약 0.5초) | 도트 입력창을 기다림 없이 바로 열기 |
| **더블 클릭** | 채팅창 열기 / 다시 더블 클릭하면 닫기 |
| **드래그** | 캐릭터 이동 (열려 있는 입력창·채팅창도 같이 따라옴) |
| **오른쪽 클릭** | 메뉴: 현재 세션·폴더 확인, 픽셀 전용 세션(새 대화), 설정/세션 선택, 폴더 골라서 새 세션, 자동 실행, 바탕화면 아이콘, 종료 |

> 캐릭터를 **종료**한 뒤 다시 켜려면 **시작 메뉴 → pixel_clau** 또는 바탕화면 아이콘을 누르세요.

> 클릭은 더블 클릭인지 구분하기 위해 약 0.26초 뒤에 반응합니다. 바로 열고 싶으면 길게 누르세요.

## 5. 캐릭터 상태 읽는 법

| 상태 | 캐릭터 | 오른쪽 아래 배지 | 소리 |
|---|---|---|---|
| 대기 | 숨 쉬듯 살짝 까딱, 가끔 눈 깜빡임 | 없음 | — |
| **처리 중** | 다리를 번갈아 움직이며 총총 걷기 | 주황 배지가 커졌다 작아졌다 | — |
| **완료** | `^ ^` 눈으로 폴짝폴짝 | 초록 배지 깜빡임 | 알림음 |
| **오류** | 멈춤 | 빨강 배지 깜빡임 | 경고음 (답을 받다 실패했을 때) |

- 완료/오류 표시는 캐릭터를 **클릭하거나 더블 클릭하면** 사라집니다.
- 오류 내용은 채팅창(더블 클릭)에 빨간 글씨로 나옵니다.

**이런 반응도 있어요**

- 입력창이 열리면 → 몸을 입력창 쪽으로 기울이고 "어!" 하고 폴짝
- 글자를 칠 때마다 → 통통 튀며 맞장구
- Enter로 보내면 → 입을 벌려 메시지를 냠냠 먹고, 총총 일하러 감
- 채팅창을 열면 → 몸을 숙이며 말풍선을 내밀어 줌

## 6. 빠른 질문 — 도트 입력창

캐릭터를 클릭하면 옆에 한 줄짜리 도트 입력창이 뜹니다.

- **Enter**: 보내기
- **Esc** 또는 **캐릭터 다시 클릭**: 닫기
- 다른 창을 클릭해도 자동으로 닫힙니다. 입력하던 내용은 남아 있어서 다시 열면 이어서 쓸 수 있어요.
- 앞 질문을 처리하는 중에 보내면 `⏳ 앞 작업이 끝나면 이어서 보냅니다` 가 뜨고, 끝나는 대로 순서대로 보냅니다.

보낸 뒤에는 캐릭터가 총총 걷다가, 답이 오면 폴짝 뛰며 알림음이 납니다. 답은 **더블 클릭 → 채팅창**에서 보세요.

## 7. 채팅창

캐릭터를 더블 클릭하면 캐릭터 옆에 말풍선 모양 채팅창이 열립니다. 화면의 약 28% 크기(FHD 기준 600×972)이고,
말풍선 꼬리가 항상 캐릭터를 가리킵니다.

| 부분 | 설명 |
|---|---|
| 맨 위 줄 | 선택된 세션 이름 · 작업 폴더. **여기를 끌면 채팅창이 이동**하고 캐릭터도 따라옵니다. |
| 대화 영역 | `나` / `Claude` 로 구분된 대화. `⚙ Edit 파일명` 같은 회색 줄은 Claude가 한 작업(파일 수정, 명령 실행 등)입니다. **마우스 휠**로 스크롤. |
| 입력칸 | **Enter** 보내기 · **Shift+Enter** 줄바꿈 |
| 전송 / 중지 버튼 | 답을 기다리는 동안 `중지`로 바뀝니다. 누르면 진행 중인 작업을 멈추고, 대기 중이던 질문도 취소됩니다. |

- 채팅창을 닫으려면 **캐릭터를 다시 더블 클릭**하세요. (실수로 닫히지 않도록 ✕ 버튼과 Esc 닫기는 없습니다.)
- 채팅창이 열려 있는 동안 1.5초마다 세션을 확인해서, 다른 곳(데스크톱 앱, 터미널)에서 진행된 대화도 실시간으로 보여 줍니다.
- 위로 스크롤해서 읽는 중이면 새 내용이 와도 그 자리를 유지합니다.
- 최근 80개 항목까지 보여 줍니다. 전체 기록은 데스크톱 앱이나 터미널에서 보세요.

## 8. 세션 고르기

**오른쪽 클릭 → 설정 / 세션 선택…**

- 세션이 **폴더별로 묶여** 있고, 최근에 쓴 폴더가 위에 옵니다. 폴더 이름 옆 숫자는 세션 개수입니다.
- **검색칸**에 입력하면 세션 이름 · 최근 질문 · 폴더 경로에서 바로 찾아 줍니다.
  **Enter**를 누르면 강조된 항목(지금 세션이 결과에 있으면 지금 세션, 없으면 첫 번째 결과)이 선택됩니다.
- 세션을 **더블 클릭**하거나 **선택** 버튼을 누르면 그 세션으로 바뀝니다.

| 열 | 뜻 |
|---|---|
| 세션 | 세션 이름. 데스크톱 앱 세션은 앱 사이드바와 같은 이름. 앞의 `●` = 최근 2분 안에 움직인 **진행 중** 세션 |
| 최근 질문 / 경로 | 마지막으로 한 질문 (폴더 줄에서는 폴더 전체 경로) |
| 출처 | `픽셀` = pixel_clau가 만든 세션 · `데스크톱` = Claude 데스크톱 앱에서 만든 세션 · `CLI` = 터미널에서 만든 세션 |
| 시간 | 마지막으로 바뀐 시각 |

- 최근 60개 세션까지 보여 줍니다. 데스크톱 앱에서 보관(Archive)한 세션은 나오지 않습니다.
- 고른 세션은 pixel_clau를 끌 때까지 유지됩니다. 다시 켜면 새 픽셀 전용 세션으로 시작해요.
- 아래쪽 **권한 모드**도 여기서 바꿉니다. ([11장](#11-권한-모드))

## 9. 새 세션 만들기

- **오른쪽 클릭 → 픽셀 전용 세션 (새 대화)**: 전용 폴더에서 깨끗한 대화를 새로 시작합니다. 가벼운 질문용.
- **오른쪽 클릭 → 폴더 골라서 새 세션…** (또는 세션 선택 창의 같은 버튼): Claude가 작업할 **프로젝트 폴더**를 고릅니다.
  그 폴더의 파일을 읽고 고치는 일을 시킬 때 쓰세요.

어느 쪽이든 첫 질문을 보내는 순간 세션이 만들어지고, 이후 질문은 계속 그 세션으로 이어집니다.

## 10. 데스크톱 앱 세션과 함께 쓰기

평소 질문은 픽셀 전용 세션으로 가므로 이 장은 **세션 선택 창에서 `데스크톱` 세션을 직접 골랐을 때만** 해당합니다.

Claude 데스크톱 앱에서 만든 세션은 **앱 밖에서 대화를 이어 쓸 수 없습니다.**
그래서 이런 세션을 골라 두고 질문하면, 같은 대화로 이어지도록 pixel_clau가 이렇게 넘겨 줍니다:

1. 질문이 **클립보드에 복사**되고, 데스크톱 앱에서 **그 세션이 자동으로 열립니다.**
2. 앱 입력창에서 **Ctrl+V → Enter**.
3. 질문이 올라가면 캐릭터가 **총총 걷기** 시작하고, 앱에서 답이 끝나면 **폴짝 + 알림음**.
4. 채팅창(더블 클릭)은 앱의 대화를 그대로, 실시간으로 보여 줍니다.

- 30분 동안 붙여넣지 않으면 기다리기를 그만둡니다.
- 앱에서 대화가 진행되는 걸 **보기만** 하고 싶을 때도, 그 세션을 골라 두고 채팅창을 열어 두면 됩니다.
- 앱으로 넘어가는 게 번거로우면 **오른쪽 클릭 → 픽셀 전용 세션**으로 돌아오세요.
- `픽셀` · `CLI` 세션은 이 과정 없이 pixel_clau 안에서 바로 답을 받습니다.

## 11. 권한 모드

pixel_clau에서 보낸 질문은 사람이 옆에서 "허용"을 눌러 줄 수 없는 방식으로 실행됩니다.
그래서 **Claude가 파일을 고치거나 명령을 실행해도 되는지**를 미리 정해 둡니다. (세션 선택 창 아래 **권한 모드**)

| 모드 | Claude가 할 수 있는 것 | 추천 상황 |
|---|---|---|
| `default` (기본) | 읽기·검색은 가능. 허락이 필요한 작업(파일 수정, 명령 실행 등)은 **거절됨** | 질문·설명·코드 읽기 |
| `acceptEdits` | 파일 수정까지 자동 허용 | 간단한 수정을 맡길 때 |
| `plan` | 계획만 세우고 아무것도 바꾸지 않음 | 작업 전에 방법부터 보고 싶을 때 |
| `bypassPermissions` | **모든 작업을 묻지 않고 실행** | 결과를 이해하고 감당할 수 있을 때만 |

- 권한 모드는 `픽셀` · `CLI` 세션에 적용됩니다. 데스크톱 앱 세션은 앱의 권한 설정을 따릅니다.
- `bypassPermissions`는 파일 삭제나 명령 실행도 확인 없이 진행하니 주의하세요.

## 12. 윈도우 시작 시 자동 실행

**오른쪽 클릭 → 윈도우 시작 시 자동 실행** 에 체크하면, 윈도우에 로그인할 때마다 자동으로 뜹니다. 체크를 끄면 해제됩니다.

- 관리자 권한은 필요 없습니다. (현재 사용자 계정에만 등록)
- 작업 관리자의 **시작 앱** 탭이나 Windows 설정 → 앱 → 시작 프로그램에도 `pixel_clau`로 보이고, 거기서 꺼도 됩니다.
- exe를 다른 폴더로 옮기면 체크가 풀린 것으로 보입니다. 다시 체크하면 새 위치로 등록됩니다.

## 13. 설정 파일과 초기화

설정은 `%APPDATA%\pixel_clau\config.json` 에 저장됩니다. (탐색기 주소창에 `%APPDATA%\pixel_clau` 입력)

| 항목 | 내용 |
|---|---|
| `x`, `y` | 캐릭터 위치 |
| `session`, `title`, `cwd` | 선택된 세션과 작업 폴더 (켤 때마다 픽셀 전용 세션으로 초기화) |
| `perm` | 권한 모드 |
| `owned` | pixel_clau가 만든 세션 목록 (세션 선택 창의 `픽셀` 표시용) |

**초기화**: pixel_clau를 종료한 뒤 이 파일을 지우고 다시 실행하면 처음 상태로 돌아갑니다.
(세션 기록 자체는 Claude Code 쪽에 있으므로 지워지지 않습니다.)

## 14. 문제 해결

**채팅창에 "claude CLI를 찾을 수 없어요"가 떠요**
Claude Code가 설치되지 않았거나 `claude` 명령을 찾을 수 없는 상태입니다. Claude Code를 설치하고 터미널에서 `claude`로 로그인하세요.
pixel_clau가 켜진 뒤에 설치했다면 **오른쪽 클릭 → 종료** 후 다시 실행해 주세요. (실행될 때의 PATH를 쓰기 때문)

**"Failed to authenticate" 오류가 나요**
로그인이 만료된 것입니다. 터미널에서 `claude`를 실행하고 `/login` 을 입력하세요.

**캐릭터가 안 보여요**
- **시작 메뉴 → pixel_clau** 로 켜 보세요. 이미 실행 중이면 아무 일도 일어나지 않습니다 (하나만 실행됨).
- 윈도우를 켰는데 자동으로 안 뜨면: **오른쪽 클릭 → 윈도우 시작 시 자동 실행** 체크를 껐다가 다시 켜 주세요.
  (v1.2.0 이하에서 켠 자동 실행은 일부 Windows 11에서 무시됩니다.) 작업 관리자 → 시작 앱에서 꺼져 있지 않은지도 확인하세요.
- 켜자마자 꺼진다면 `%APPDATA%\pixel_clau\error.log` 에 오류 내용이 남습니다.
- 모니터 구성을 바꿨다면 저장된 위치가 화면 밖일 수 있습니다. 작업 관리자에서 `pixel_clau`를 끝내고,
  `config.json`에서 `"x"`, `"y"` 줄을 지운 뒤 다시 실행하세요.

**질문을 보냈는데 파일을 안 고쳐요**
권한 모드가 `default`이면 파일 수정이 거절됩니다. `acceptEdits`로 바꿔 보세요. ([11장](#11-권한-모드))

**데스크톱 앱 세션에 질문했는데 앱이 안 열려요**
Claude 데스크톱 앱이 설치되어 있어야 합니다. 앱 없이 쓰려면 `CLI` 세션을 고르거나 새 세션을 만드세요.

**채팅창 내용이 앱과 달라 보여요**
채팅창은 열려 있는 동안 1.5초마다 갱신됩니다. 닫았다가(더블 클릭) 다시 열면 즉시 새로 읽습니다.

**도트 글꼴로 보고 싶어요**
[Galmuri](https://galmuri.quiple.dev/) 또는 둥근모꼴을 설치하면 입력창과 채팅창 제목에 자동으로 쓰입니다. 없으면 Consolas로 표시됩니다.

## 15. 제거하기

1. **오른쪽 클릭 → 윈도우 시작 시 자동 실행** 체크 해제
2. **오른쪽 클릭 → 종료**
3. `pixel_clau.exe` 와 `%APPDATA%\pixel_clau` 폴더를 지웁니다.
4. 시작 메뉴 / 바탕화면의 `pixel_clau` 바로가기를 지웁니다.

Claude Code와 세션 기록에는 영향이 없습니다.

## 16. 개발자용

### 소스로 실행
```
pythonw pixel_clau.pyw
```
Python 3.8+ 표준 라이브러리만 씁니다 (Windows).

### exe 빌드
```
python -m venv .venv-build
.venv-build\Scripts\pip install pyinstaller pillow
.venv-build\Scripts\python build.py
```
→ `dist\pixel_clau.exe` (아이콘은 버튼과 같은 스프라이트 데이터로 생성)

### 동작 방식
- **픽셀 / CLI 세션**: 세션 폴더에서 `claude -p --resume <세션ID> --output-format stream-json` 실행. 프롬프트는 stdin으로 전달.
  픽셀 전용 세션은 첫 질문 때 `--resume` 없이 `%APPDATA%\pixel_clau\pixel-claude`에서 만들어짐.
  답(`result`)이 오면 바로 다음 질문을 받되, 프로세스가 stop 훅 등으로 아직 살아 있으면 끝날 때까지 줄 세워 둠
  (같은 세션에 두 프로세스가 동시에 쓰지 않도록).
- **데스크톱 앱 세션**: 질문을 클립보드에 넣고 `claude://code/continue?session=<앱 세션ID>` 링크로 앱에서 세션을 엶.
  완료 여부는 세션 파일의 마지막 메시지(`stop_reason: end_turn`)로 판단.
- **대화 기록**: `~/.claude/projects/*/*.jsonl` (또는 `CLAUDE_CONFIG_DIR`)을 **새로 추가된 부분만** 읽어서 따라감.
  다른 클라이언트가 옆가지로 붙인 대화는 건너뛰고, Claude Code처럼 현재 대화 줄기만 보여 줌.
- **데스크톱 앱 세션 정보**: `%APPDATA%\Claude\claude-code-sessions` (앱 사이드바 제목, 폴더, 보관 여부)
- **자동 실행**: `HKCU\...\CurrentVersion\Run` 의 `pixel_clau` 값 + `HKCU\...\Explorer\StartupApproved\Run` 의 "사용" 기록
  (이 기록이 없으면 Windows 11이 Run 항목을 건너뛰는 경우가 있음)
- **바로가기**: 첫 실행 시 시작 메뉴 `Programs\pixel_clau.lnk` 자동 생성. 스크립트 버전 아이콘은 스프라이트로 `%APPDATA%\pixel_clau\pixel_clau.ico` 생성
- **오류 기록**: `%APPDATA%\pixel_clau\error.log` (pythonw / exe에는 콘솔이 없으므로)
- **중복 실행 방지**: 이름 있는 뮤텍스 `Local\pixel_clau`
